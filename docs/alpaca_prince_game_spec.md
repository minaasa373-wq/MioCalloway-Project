# あるぱかプリンス 横スクロールシューティング 仕様メモ

このメモはClaude Codeにそのまま渡して開発を始めるための設計書です。仮の数値・案には「（仮）」を付けています。気になるところは直してから渡してください。

## 1. ゲーム概要

- タイトル：あるぱかプリンス（仮）
- ジャンル：横スクロールシューティング（弾幕系・グレイズあり）
- 主人公：あるぱかプリンスが自機（アルパカ型飛行艇）に搭乗して出撃
- 世界観：紫×白×ゴールドの貴族的な「アルパカ王国」の空を舞台にした、優雅だけど熱いシューティング
- 開発スコープ：まずは1ステージ完結のMVP（最小動作版）を目指す

## 2. 画面・技術仕様

- 画面サイズ：1280×720（16:9）（仮）。ウィンドウ幅に合わせて拡縮対応
- 使用ライブラリ：Phaser 3（CDN読み込み、単体HTMLにまとめる）
- ファイル構成案：
  - index.html（メイン）
  - assets/images/（スプライト類）
  - assets/audio/（BGM・SE）
- 公開先：GitHub Pages（過去の制作物と同じ運用）

## 3. 操作方法

- 移動：矢印キー / WASD（8方向）
- ショット：Zキー or スペース（押しっぱなしで連射）
- ボム：Xキー
- ポーズ：Escキー
- （将来的にタッチ操作にも対応したい場合は、バーチャル十字キー＋ボタンを追加）

## 4. 自機（あるぱかプリンス号）

- HP：ハート8個（仮、画像参考と同じ）。被弾でハート1個減少
- 当たり判定：見た目より小さい中央の判定（弾幕シューティングの定番手法）
- 移動速度：通常速度＋低速移動ボタン（任意：判定を見やすくするため）
- ショット：
  - 通常：前方ストレートのレーザー（紫）
  - パワーアップで弾数・太さが強化（最大レベル仮で3段階）
- ボム：画面内の敵弾を一定時間無効化＋敵にダメージ。初期所持数（仮）2発

## 5. グレイズシステム

- 自機の当たり判定の少し外側に「グレイズ判定」を設定
- 敵弾がグレイズ判定内を通過するとグレイズカウント＋スコア微増
- 一定回数グレイズするとパワーゲージが少し溜まる（任意要素）

## 6. アイテム

| アイテム | 効果 |
|---|---|
| P（パワーアップ） | ショットレベルが1段階上がる |
| 金の星 | スコア加算 |
| 紫のクリスタル | スコア加算（星より少し低め） |
| 羊シルエット（ボム） | ボム所持数＋1 |
| ハート（任意） | HP回復1 |

## 7. 敵キャラクター（ステージ1：ROYAL ALPACA SKYLINE）

| 敵名 | 動き | 攻撃パターン | HP |
|---|---|---|---|
| タレット型ロボ（箱型） | 地上設置・固定 | 前方にストレート弾を一定間隔で発射 | 低 |
| シルクハット羊 | ゆっくり左右に揺れながら接近 | 自機狙いの単発弾 | 低〜中 |
| 羽つき子アルパカ | 画面を横切るだけ | 攻撃なし（撃破でボーナススコア） | 極低 |
| 飛行船（ボス） | ステージ終盤に出現、画面内をゆっくり移動 | 複数パターン（扇状弾、レーザー、子機展開など） | 高（HPバー表示） |

- 出現タイミングはタイムライン形式でスクリプト化（例：開始10秒でタレット3体、30秒で羊隊列、など）

## 8. ステージ構成

- ステージ1の長さ：2〜3分（仮）
- 背景：パララックス3層（遠景：城と山脈／中景：建物・橋／近景：花や柱などの地形装飾）
- 終盤30〜45秒でボス戦に移行
- ボス撃破でステージクリア→リザルト画面

## 9. UI / HUD

- 左上：プリンスの顔アイコン＋名前＋HPハート表示
- その下：現在スコア
- 中央上：ステージ名表示（"STAGE 1 - ROYAL ALPACA SKYLINE"）
- 右上：ハイスコア／ポーズボタン
- 左下：パワーアップアイコン（現在のショットレベル表示）
- 中央下：ボム所持数（羊アイコン）
- 右下：グレイズカウント＋ゲージ

## 10. スコアルール

- 敵撃破：種類ごとに基礎点（タレット小、羊中、子アルパカ低、ボス大）
- ショットレベルが高いほどスコア倍率アップ（任意）
- グレイズ：1回ごとに微量加点
- ステージクリアボーナス：残機・残HPに応じて加算

## 11. 勝敗条件

- HPが0になると残機消費→0でゲームオーバー
- ボス撃破でステージクリア（MVPではここまで作れば十分）

## 12. オーディオ

- BGM：今回作った「アルぱかぱか伝説」をmp3で書き出して使用（alpaca_prince_bgm.mp3）
- SE（要準備、まだ手元にない）：
  - ショット発射音
  - 敵撃破音（小／大＝ボス用）
  - 自機被弾音
  - アイテム取得音
  - ボム発動音
  - パワーアップ音
  - ステージクリア音
  - ゲームオーバー音
- SEが手元にない場合は、まずWeb Audio APIで簡易ビープ音を仮置きしてもOK（後で本番音源に差し替え）

## 13. アート素材（後回しでOK・仮図形での先行開発を推奨）

- 自機スプライト：透過背景、正面／上向き／下向きの3パターン
- 敵スプライト：タレット、シルクハット羊、子アルパカ、ボス飛行船
- 弾・エフェクト：自機レーザー、敵弾（紫クリスタル）、アイテム各種、爆発エフェクト
- 背景：パララックス用3層
- UIパーツ：ハート、パワーアップアイコン4種、ボムアイコン、グレイズメーター枠
- 参考資料：既存の2枚のイラスト（キャラ設定画＋ゲーム画面イメージ）を世界観・配色のリファレンスとして使用

## 14. 開発の進め方（MVP優先）

1. Phase 1：仮図形（丸・四角）で自機移動＋ショット＋敵1種＋当たり判定＋スコアを動かす
2. Phase 2：グレイズ・HP・ボム・アイテムドロップを追加
3. Phase 3：パララックス背景＋敵出現タイムライン＋ボス
4. Phase 4：本番アート差し替え
5. Phase 5：BGM/SE組み込み
6. Phase 6：UI/HUD仕上げ
7. Phase 7：GitHub Pagesで公開
